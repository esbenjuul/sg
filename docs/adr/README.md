# Architecture Decision Records

ADRs document significant technical choices for this project.

## Convention

- Files are numbered sequentially: `0001-short-title.md`, `0002-…`
- Each ADR has a **Status**: `Proposed`, `Accepted`, or `Superseded`
- When superseding, link the new ADR from the old one and set the old status to `Superseded`
